# Case A — Dark matter: prompts

The task core, identical in all three arms. The arm prompts as sent are in `prompts/`: `arm-a.txt` is the core alone, `arm-b.txt` adds the written placebo, and `arm-c.txt` adds the trigger sentence and the skill body (generated by `npm run arm-c`). The system prompt is `prompts/system.txt`.

## Task core

```
Identify the main research programmes currently competing to explain dark matter. For each, set out where the programme stands today. Finish by ranking them from the programme in the best current shape to the worst, with a brief justification.
```
